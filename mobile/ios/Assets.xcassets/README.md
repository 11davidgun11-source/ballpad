# BallPad app icon

Original artwork generated with the built-in image-generation tool on 2026-09-16,
then normalized to 1024 × 1024 for the universal iOS/iPadOS app-icon catalog.
Replaces the earlier flaming-ball artwork.

Prompt: Create a finished iOS/iPadOS app icon artwork for BallPad. Square 1024x1024 full-bleed image, perfectly opaque, no pre-rounded corners. Flat minimalist geometric design: a bold black and white tessellation that evokes the pentagons and hexagons of a soccer ball, filling the entire square like an abstract checkerboard soccer-ball surface. One large crisp central black pentagon surrounded by white polygon panels and black polygon panels towards the edges; balanced symmetrical graphic composition. Pure black and white only. Clean vector-like hard edges. No realistic ball object, no 3D, no lighting, no shadows, no gradients, no texture, no flames, no text, no logos, no inset icon or mockup. Strong recognizable shapes at small home-screen size.

The native CMake build invokes `scripts/native/lib/app_icon.py` to compile the
catalog for the chosen SDK and merge generated icon metadata into Info.plist.
